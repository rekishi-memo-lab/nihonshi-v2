# 暫定106講案と、残っている問題点

**この案は暫定。確定したものとして扱わない。**
V1 の通史246授業を、時代の順と「1講1つの学習目標」を優先して並べ直したたたき台。教科書の目次、実際の入試問題、共通テストの出題構成と照らして作り直す（`docs/roadmap.md`）。

- 各講に V1 の授業（セットid:授業番号）を割り当てた。V1 の授業は V1 リポジトリ（rekishi-memo/nihonshi）の通史のもの。
- 「今の素材（分）」＝割り当てた V1 授業の音声の長さの合計。V2 の授業の長さではない。V2 は本文3,000〜3,600字前後、音声10〜13分ほどを目安にする（読み上げ1分＝約313字で計算）。

## 5. 分野の扱い

- 経済・社会・外交が、政治の講の付け足しになっていないかを確かめる。現在は経済9・社会9・外交12講を独立させた。
- 時期が近いだけで組み合わせた講は、前の案から分けた（例：「ワシントン体制と社会運動」→ 86 と 87）。同じ観点で全講を見直す。

## 6. この案の数字の限界

- 数字は V1 の授業から機械的に数えたもの。V1 の自動の色づけには誤りがある（例：「おとなしい」の「おとな」が用語として色づけされている）。
- 教科書（山川『詳説日本史』）の目次・本文とは、まだ照らしていない。
- 過去問の集計は、アプリの答えの語が試験の文に出たかを数えただけで、正解・選択肢・リード文の区別がない。共通テストは集計に入っていない。
- 講ごとの学習目標の文は、まだ全部は書いていない。
