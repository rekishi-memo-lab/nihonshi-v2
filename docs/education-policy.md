# 教育方針（V2）

この文書は、V2 の教材が「何をわからせるか」「どの試験に、どこまで対応するか」を決める。
授業本文の文体や見た目の基準は、別の文書（今後作る書き方の基準）で決める。

---

## 1. めざす理解

覚えた用語を並べられることではなく、次のことができる状態をめざす。

- その出来事が**いつ・どの順で**起きたかを言える。
- **なぜ**起きたか（背景・原因・きっかけ）を説明できる。
- その結果、**何が変わったか**（制度・権力・経済・社会・対外関係）を説明できる。
- 似た出来事や前後の時代と**比べて**、同じ点と違う点を言える。
- 初めて見る史料や図表でも、知っている知識と結びつけて**読み取れる**。

## 2. 歴史理解の観点

各授業・各知識は、次の観点のどれにかかわるかを意識して作る（知識台帳の「分野」と「関係」に対応する）。

| 観点 | 見ること | 例 |
|---|---|---|
| 時系列 | 前後関係、同時代の出来事、時期区分 | 院政 → 保元・平治の乱 → 平氏政権 |
| 背景と原因 | 長い背景、直接の原因、きっかけを分ける | 背景：荘園の拡大／原因：受領の取り立て／結果：寄進 |
| 政治制度と権力構造 | だれが決め、だれが従い、何で正当化したか | 摂関・院・執権・管領・老中 |
| 経済・社会の変化 | 生産・流通・貨幣・税・身分・村と都市 | 二毛作 → 定期市 → 貨幣経済 |
| 外交と国際関係 | 東アジアの秩序、交易、戦争、条約 | 冊封・朝貢、勘合、四つの口、条約改正 |
| 文化と思想 | その時代の社会・政治・外交とのつながり | 国風文化と東アジアの変化 |
| 人物と制度 | 人物が何を作り、何に動かされたか | 人物は「何をした人か」を必ず添える |
| 連続と変化 | 前の時代から何を受け継ぎ、何が変わったか | 律令の税 → 名・負名 → 荘園公領制 |

文化史も通史の一部として扱う。作品名を並べるだけにせず、担い手・背景・前後の文化との違いを示す。

## 3. 入試への対応

| 力 | 主に問われる試験 | 教材でやること |
|---|---|---|
| 基本知識の確実な理解 | 共通テスト・全大学 | 共テで必要な知識を本文の軸にする |
| 史料・図表・地図の読解 | 共通テスト・私大 | 本文に地図・図表を入れ、読み方を示す。有名史料は目印の言葉を示す |
| 正誤の判定 | 全試験 | 混同しやすい組み合わせを台帳の「対・混同注意」の関係で管理し、ひっかけの例を示す |
| 年代整序 | 共通テスト・私大 | 時系列と、順番を決める理由（因果）をセットで示す |
| 因果関係の判断 | 共通テスト・私大 | 背景・原因・結果を台帳の関係で結ぶ |
| 詳細な知識 | 難関私大 | 通常の授業では軽く触れ、深掘りで扱う。ただし理解に必要なら本文で扱う |
| 初見資料・未知の設問への応用 | 共通テスト・難関私大 | 知識を単独でなく関係で覚えさせ、類推できるようにする |

## 4. 知識の深さ：4つの独立した軸

知識の扱いを「重要度」1本で決めない。次の4つを**別々に**記録し、組み合わせて扱いを決める。

| 軸 | 問い | 値の例 |
|---|---|---|
| ① 入試での重要度 | どの試験で、どの程度問われるか | 試験ごとに「必須／頻出／標準／発展／対象外／未判定」 |
| ② 教科書での扱い | 教科書のどこに、どう載っているか | 本文・注・図版や説明文・史料・コラム・記載なし・未確認 |
| ③ 必要な説明の深さ | 理解のために、どこまで説明が要るか | 名前だけ／一文の説明／因果の説明／構造の説明（図表が要る） |
| ④ 過去問での確認状況 | 実際の出題で確かめたか | 原本で確認／二次資料で確認／未確認、と出題の役割（正解・選択肢・リード文など） |

### 組み合わせの考え方

- **教科書外でも、①か③が高ければ通常の授業で扱う。** 理解を助ける短い逸話も、本筋の理解に必要なら本文に残す。
- **教科書の本文にあっても、①が低く③も浅ければ、名前を出すだけでよい。**
- ①は④の根拠から判断する。④がまだ「未確認」の間は、①を確定させない（「暫定」と記す）。
- 出題の回数だけで①を決めない。正解として問われたのか、選択肢やリード文に出ただけなのかを区別する。
- ある大学の全学部の傾向と、特定の学部の傾向を混同しない。

### 授業での扱いの目安

| 扱い | 条件の目安 |
|---|---|
| 本文で詳しく説明する | ①が「必須・頻出」、または③が「因果・構造」 |
| 本文で一言触れる | ①が「標準」で③が「名前・一文」 |
| 深掘りで扱う | ①が「発展」（難関私大）で、本文の理解には要らない |
| テーマ史で扱う | 時代をまたいだ比較や移り変わりが主になる知識 |
| 扱わない | ①が「対象外」で、理解にも要らない |

これは目安で、最後は授業の学習目標で決める。

## 5. 反復の扱い

| 種類 | 扱い |
|---|---|
| 同じ授業の中の言い直し（本文・入試欄・まとめで同じことを言う） | 減らす。入試の問われ方とまとめは1か所にまとめる |
| 前の授業の内容をもう一度説明する | 必要な最小限にする（想起の一文や参照） |
| 比較・因果の回収・発展のための再登場 | 残す。目的を台帳の「再登場」に書く |

## 6. 通史とテーマ史

- **通史**：その時代の因果を説明するのに必要な知識を、時系列で扱う。
- **テーマ史**：時代をまたいだ比較と移り変わり（貨幣・土地制度・外交・交通など）を扱う。通史の知識を使い、通史の授業へ戻れるようにする。
- 同じ知識を両方で扱うときは、通史で「初めて詳しく扱い」、テーマ史では「比較」の目的で再登場させる。

## 7. 正確さ

- 事実は根拠と結びつけて記録する（知識台帳）。確かでない説は「〜とされる」「異説あり」と書き、台帳に記録する。
- 既存の教材（V1 など）の記述も、根拠と照らすまでは「未確認」として扱う。
